## 适用规格条目

### R-003-001 R-003-001 单任务失败不得中断同轮其他任务 （来源: `specs/SPEC-003-job-error-isolation.md`，版本: v1）

`Scheduler.run_pending()` 执行到期任务时，某个任务函数抛出异常，
**不得**中断同一轮中其余到期任务的执行；其余到期任务必须照常执行。

### R-003-003 R-003-003 on_error 配置项 （来源: `specs/SPEC-003-job-error-isolation.md`，版本: v1）

`Scheduler` 必须提供 `on_error` 属性，默认值为 `None`，
允许在构造后赋值，例如 `scheduler.on_error = handler`。

### R-003-002 R-003-002 失败必须可观测 （来源: `specs/SPEC-003-job-error-isolation.md`，版本: v1）

任务抛出的异常必须交给 `Scheduler` 上配置的 `on_error` 回调（可调用对象），
参数为 `(job, exception)`。若未配置 `on_error`，异常必须被吞掉并记录到模块级 logger
的 `warning` 级别，且**不得**再向上抛出。

### R-002-001 R-002-001 next_run 取最早任务 （来源: `specs/SPEC-002-next-run-and-idle.md`，版本: n/a）

`Scheduler.next_run`（即 `get_next_run()`）必须返回所有任务中最早的 `next_run` 时间；
没有任务时返回 `None`。传入 `tag` 时只在匹配该标签的任务中取最早值。

### R-003-004 R-003-004 既有行为保持 （来源: `specs/SPEC-003-job-error-isolation.md`，版本: v1）

- 正常任务仍然按 `next_run` 升序执行（见 SPEC-001 R-001-002）。
- 返回 `CancelJob` 的任务仍然被取消（见 SPEC-001 R-001-003）。
- `run_pending()` 仍然不补跑错过的周期（见 SPEC-001 R-001-001）。
- `run_all()` 同样必须隔离异常，行为与 `run_pending()` 一致。

### R-002-002 R-002-002 idle_seconds 计算 （来源: `specs/SPEC-002-next-run-and-idle.md`，版本: n/a）

`Scheduler.idle_seconds` 必须返回距离下一次运行还有多少秒；
当没有任务或没有下次运行时返回 `None`。

### R-001-004 R-001-004 run_all 语义 （来源: `specs/SPEC-001-scheduler-core-behavior.md`，版本: n/a）

`Scheduler.run_all(delay_seconds)` 必须无视是否到期，执行**全部**任务，并在相邻任务之间
等待 `delay_seconds` 秒。

### R-002-003 R-002-003 模块级快捷函数 （来源: `specs/SPEC-002-next-run-and-idle.md`，版本: n/a）

模块级 `get_jobs` / `clear` / `cancel_job` / `next_run` / `idle_seconds` / `every`
必须等价于默认 `Scheduler` 实例上的同名方法。

    scheduler = schedule.Scheduler()
    records = []

    class _Capture(logging.Handler):

            records.append(record)

    logger = logging.getLogger("schedule")
    handler = _Capture()

    logger.setLevel(logging.WARNING)

def test_on_error_handler_itself_failure_does_not_break_other_jobs():
    """R-003-005: on_error 回调自身抛异常时不得影响其余任务，并记录 warning。"""

    scheduler = schedule.Scheduler()
    ran = []
    records = []

    class _Capture(logging.Handler):
        def emit(self, record):
            records.append(record)

    def bad_handler(job, exception):
        raise ValueError("handler exploded")

    logger = logging.getLogger("schedule")
    handler = _Capture()
    logger.addHandler(handler)
    previous_level = logger.level
    logger.setLevel(logging.WARNING)
    try:
        scheduler.on_error = bad_handler
        _make_due(scheduler, _boom)
        _make_due(scheduler, lambda: ran.append("second"))

        scheduler.run_pending()  # 不应抛出
    finally:
        logger.removeHandler(handler)
        logger.setLevel(previous_level)

    assert ran == ["second"]
    warnings = [record for record in records if record.levelno == logging.WARNING]
    assert warnings, "on_error 回调自身失败必须记录一条 warning 日志"
