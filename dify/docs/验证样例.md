# 验证样例：忘事管理局

前置：`deploy/docker-compose.full.yaml` 已起栈，`LostFound.yml` 已导入并发布，拿到 `/chat/<code>` 链接（或 API Key）。

## 用例 A：登记

输入 `存：充电宝借给隔壁老张了，记得要回来`

预期：回复「已归档：…（以后问「查：关键词」就能翻出来）」；记忆 +1。

## 用例 B：查询

输入 `查：充电宝`

预期：

```
档案里记着：
· 充电宝借给隔壁老张了，记得要回来
记性这东西，交给我就对了。
```

重复登记同一条时会自动去重。

## 用例 C：兜底

输入 `你好` → 返回使用说明，不写入记忆。

## 用例 D：跨会话

新开会话再 `查：充电宝`，仍能召回（记忆在 PowerContext，不在上下文窗口）。

## 核对记忆

```bash
docker exec $(docker ps --format '{{.Names}}' | grep memory-bridge) \
  python -c "import urllib.request,json;print(json.loads(urllib.request.urlopen('http://127.0.0.1:19080/health').read())['memories'])"
```

## 常见问题

| 现象 | 原因 |
|---|---|
| 回「查无此档」 | 关键词没命中（分词/大小写），换更具体的词 |
| 回复 500 | memory-bridge 未起，或 DSL 的 `MEMORY_BRIDGE_URL` 指错 |
| 记忆不增长 | 存分支要求输入含「存：」或「登记」 |
