# DeepSeek 配置

## 本次实际使用

- 提供商：DeepSeek 官方 API。
- 模型：`deepseek-flash`，来自本机已有 Key 的 `/v1/models` 实际返回值。
- 推理模式：`thinking: {"type":"disabled"}`。
- 输出：`response_format: {"type":"json_object"}`。
- 调用：Dify 的两个原生 LLM 节点，温度分别 0.1 / 0.4，每节点最多生成 1400 tokens。适配层硬上限 1800 tokens，输入消息预算 65 KB。
- 首次校验及验收均是真实付费请求，未使用预录结果替代模型。

## 自动配置

在运行 `scripts/start.sh` 或 `scripts/bootstrap_app.py` 的终端提供 `DEEPSEEK_API_KEY`，脚本会登录本地 Dify，校验凭据后保存。Key 加密保存在 Dify 的数据库中，依赖实例的 `SECRET_KEY` 和存储，不会写入 `.runtime/connection.json` 或 DSL。

不建议把 Key 写进 shell 历史。Linux 可使用 README 的 `read -rsp`。Windows 环境变量不会自动传入 WSL，本次部署通过父进程读取环境变量、标准输入传给 `bootstrap_app.py --key-stdin`，未把真实 Key 拼进命令行。以后仅重启本次实例时可直接在 WSL 执行：

```bash
cd /opt/lostfound-ai-20261113
bash scripts/start.sh
```

## 手动配置已有 Dify 0.15.3

先启动本包后端及 PowerContext，并保证 Dify 能通过 Docker 网络访问 `memory-bridge:19080`。在 Dify 设置 → 模型供应商 → OpenAI-API-compatible → 添加自定义模型，填写：

| 配置 | 值 |
|---|---|
| 模型名称 | `deepseek-flash` |
| 模型类型 | LLM / Chat |
| API Key | 自己的 DeepSeek Key |
| API endpoint URL | `http://memory-bridge:19080/model/v1` |
| 上下文长度 | `32768` |
| 最大 token 上限 | `1800` |
| Function Calling | Not Support |
| Stream Function Calling | Not Support |
| Vision | Not Support |
| Stream delimiter | `\n\n` |

导入根目录 `LostFound.yml`，设置工作流环境变量：

- `MEMORY_BRIDGE_URL=http://memory-bridge:19080`。
- `BUREAU_TOKEN`：本实例 `.env` 的 `BUREAU_SERVICE_TOKEN`，作为 secret 变量。提交用 DSL 中只有 `__SET_BY_BOOTSTRAP__` 占位符，自动脚本会注入运行值。

点击发布后打开 WebApp。只填写提供商、未替换工作流 Token 会得到明确的档案读取失败，不能正常办案。

## 为什么有协议适配层

Dify 0.15.3 的通用提供商会过滤未声明参数。直接在模型配置里增加 `thinking` 和 `response_format` 不能保证传给 DeepSeek；旧版内置 DeepSeek 提供商又预置了旧模型名。本版以通用提供商调用 `backend/model_proxy.py`，由它固定设置新接口参数，转发官方 API，并将响应转换为 Dify 需要的 SSE。

适配层不决定物品、意图或案件，不执行 PowerContext 操作。最终模型响应、token 数和工作流执行都来自真实调用。适配层的上游地址固定，不允许用户指定任意转发目标。

## 更换 Key 或模型

更换 Key：在 Dify 提供商页面更新，或重新给 `bootstrap_app.py` 提供新环境变量。无须修改 DSL。代码、证据、公开聊天页都不显示 Key。

本版只验证 `deepseek-flash`。更换模型不能只改一个 `.env` 字段：还需要修改 `build_dsl.py` 的模型名、提供商设置、适配层模型白名单，重新生成 DSL 并重跑自然语言和 JSON 校验。本机接口也返回了 `deepseek-v4-pro`，但本次未选择它作为应用模型。

自定义提供商的 Dify token 价格默认可能显示为零；实际费用以 DeepSeek 账号账单为准。审计日志不含提示词或 Key，备份日志时仍应把用户档案与凭据分开管理。
