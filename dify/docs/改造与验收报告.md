## 联调发现并修复的问题

1. 指定三件物品时模型返回 `items`，旧校验不接受该字段。现已明确提取契约、校验名称确实来自原话，并让指定清单优先于推荐清单。
2. 多个日期都有“拍照”时，只按活动查询会过度报歧义。现按明确日期筛选；“这次”默认最近一次。
3. 只支持完成和排除不足以表达撤回。新增 `pending` 反馈，拿出包或明确未完成会撤回确认时间；负向语句不能误打勾。
4. Markdown 标签缺少间距、表格行之间插入空行，导致浏览器出现字面星号或表格失效。现已修正并在浏览器确认真实表格和加粗标签。
5. 手写鉴权 header 不能利用旧版 Dify 的日志遮罩。现改用其专用认证字段，并实查遮罩结果。

早期失败没有伪装成通过；最终 `evidence/ai-e2e.json` 为修复完成后的真实完整复验。
